# AS5600 ESP8266 固件说明

> 固件目录：`esp32s3_as5600/as5600_tracker_8266/`
> 硬件：NodeMCU 1.0 (ESP-12E)　板载：AS5600 磁编码器（I2C）+ 光电零位传感器（GPIO12）
> 功能：20Hz UDP 上报角度 / 光电零位事件 / WiFi 配网重连 / 双通道 OTA

---

## 1. 文件结构

| 文件 | 说明 |
|------|------|
| `as5600_tracker_8266.ino` | 主程序（loop 采集 + UDP 上报 + 光电处理） |
| `AS5600Sensor.h` | AS5600 驱动：I2C 读取、跨圈 unwrap 累积角度、双读校验 |
| `StateStorage.h` | EEPROM 持久化：WiFi 配置、累积角度（带 magic 校验） |
| `WiFiManager.h` | WiFi 连接/重连/退避、AP 配网页面（端口 80） |
| `OTAUpdate.h` | HTTP OTA（端口 8080）+ ArduinoOTA 双通道更新 |
| `wifi_diag/` | WiFi 信号诊断工具（独立程序） |
| `EEPROM_Write_Config/` | EEPROM 配置写入工具（预烧 WiFi） |

## 2. 硬件接线

```
AS5600 VCC -> 3.3V      AS5600 SCL -> D1 (GPIO5)
AS5600 GND -> GND       AS5600 SDA -> D2 (GPIO4)
AS5600 DIR -> GND (旋转方向)
光电零位    -> D6 (GPIO12, INPUT_PULLUP, 触发沿=遮挡)
板载 LED    -> GPIO2 (低电平亮)
```

## 3. 主程序流程

```
setup():
  串口 115200 → 存储初始化 → 光电中断(CHANGE) → AS5600 检测
  → 恢复累积角度(EEPROM) → WiFi 连接(3 次重试) → UDP 8091 → OTA 启动

loop() (约 2ms 周期):
  wifi.reconnectTick()      # 断线按退避重连(5s/10s/30s)
  OTAUpdate::handle()       # HTTP OTA + ArduinoOTA 处理
  LED 状态                 # 联网常亮, 断线闪烁
  光电事件处理             # zeroFlag → 读角度 → 补偿 → UDP 重发 3 次
  20Hz 角度上报           # {"angle","raw","tick","rssi","ver"}
  卡死检测                 # raw 连续不变告警
  角速度计算               # 供光电触发角度补偿
  周期保存累积角度         # 变化>2° 才写 EEPROM(防磨损)
```

### UDP 上报格式

```json
// 角度包 (20Hz)
{"angle":1234.56,"raw":1598,"tick":123456,"rssi":-70,"ver":"2.0.2"}

// 光电零位事件 (触发时)
{"event":"zero","raw":672,"angle":781.79,"tick":234567,"rssi":-70,"ver":"2.0.2","zc":106}
```

- `angle`：AS5600 跨圈**累积角度**（ESP 域，物理角 × 4，即传动比）
- `zc`：光电触发总计数（诊断用）
- 服务器 8091 端口监听，`event:"zero"` 用于锚定物理 0°

## 4. 光电零位逻辑（状态机，v2.0.2）

挡片扫过传感器：`开始遮挡(FALLING) → 遮挡中(LOW) → 出遮挡(RISING)`。

```cpp
// CHANGE 中断状态机: 完整遮挡只触发一次
FALLING (LOW):  从未遮挡→遮挡中, 记录遮挡开始时刻 (system_get_time)
RISING (HIGH):  遮挡中→未遮挡, 遮挡宽度 ≥5ms 才算有效, zeroFlag++
```

- **一次完整遮挡 = 一个事件**：防挡片边缘抖动/云台在 0° 附近摆动重复触发
- **宽度 <5ms 过滤**：信号毛刺（临界区抖动）丢弃
- **ISR 用 `system_get_time()`**：ESP8266 ISR 安全时钟（`millis()` 在 ISR 不可靠）
- **触发角度补偿**：loop 读取滞后于触发时刻，用最近角速度回推到遮挡完成时刻的角度

## 5. 编译与刷入

```bash
# 编译（生成 build_vXXX/固件.bin）
arduino-cli compile --fqbn esp8266:esp8266:nodemcuv2 \
  --build-property build.flash_size=4M \
  --output-dir esp32s3_as5600/as5600_tracker_8266/build_vXXX \
  esp32s3_as5600/as5600_tracker_8266/

# USB 刷入（首次 / 串口可用时）
arduino-cli upload --fqbn esp8266:esp8266:nodemcuv2 \
  --port /dev/cu.usbserial-XXX \
  --input-dir .../build_vXXX \
  esp32s3_as5600/as5600_tracker_8266/

# WiFi OTA（HTTP，固件需 ≥2.0.0 才支持）
curl -s -m 120 -F "token=ptz2026" \
  -F "sketch=@.../build_vXXX/as5600_tracker_8266.ino.bin" \
  http://192.168.31.66:8080/update
```

# 固件版本说明

## v2.0.2（当前）
**光电触发重构——解决"多余/错误触发"**
- `CHANGE` 中断 + 状态机：完整遮挡（FALLING→RISING）只触发一次
- 遮挡宽度 ≥5ms 才有效，过滤信号毛刺
- ISR 改用 `system_get_time()`（`millis()` 在 ESP8266 ISR 不可靠）
- 触发时刻角度补偿（消除 loop 读取滞后导致的锚定角度偏差）
- 版本号 2.0.2

## v2.0.1
**修复光电偶发不上报 + 版本识别**
- 去掉 `digitalRead == LOW` 二次确认（挡片扫过快时误丢事件）
- zero 事件 UDP 重发 3 次（弱信号抗丢包）
- 新增 `zc` 触发计数上报
- 修复 EEPROM 累积角度 magic 校验（旧数据无标记则从 0 开始）
- 修复 `setTotal` 每 5s 写 EEPROM 的磨损缺陷（改为变化 >2° 才写）
- 修复 WiFiManager `millis()` 回绕（49.7 天）
- 版本号 2.0.1

## v2.0.0
**首次引入 OTA 与配套修复**
- 新增 `OTAUpdate.h`：HTTP OTA（8080，口令 `ptz2026`）+ ArduinoOTA 双通道
- UDP 上报加 `ver` 版本字段
- 版本号 2.0.0

## v1.x（历史，未打 tag）
- 20Hz UDP 角度上报、光电零位 FALLING 触发
- WiFi 配网（AP 模式）/ 重连退避
- EEPROM 累积角度保存（5s 一次，有磨损风险）
- 无 OTA（只能 USB 刷入）——"无法 WiFi 更新固件"的历史根因

## 6. 服务器端配套（与固件交互）

| 服务器逻辑 | 说明 |
|-----------|------|
| UDP 8091 监听 | 收角度包 + `event:"zero"` |
| 光电锚定 `_reanchor_zero` | 光电触发 → zero_angle = 触发角度（带去重，5s/180°ESP 内只锚定一次） |
| 漂移恢复 | 毛刺(<120°ESP)过滤保持基准；大跳变(≥120°ESP)接受为新基准 |
| 固件版本显示 | `/api/encoder` 返回 `ver`，前端 AS5600 面板显示 `fw` |
